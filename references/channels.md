# WorkBuddy 积分渠道情报

> 最后核实日期：2026-10-22（信息检索自公开攻略与官方协议；活动为赛季制、随运营轮换，一切以客户端当期页面显示为准）

## 一、每日可领（核心）

### 1. Buddy 加油站（每日签到）
- 收益：每天 100 通用积分；连签第 7 天额外 1000 积分（7 天一个循环，拿了重计）
- 入口：桌面客户端左下角头像 →「Buddy 加油站」；登录时有时也会弹窗
- 关键事实：
  - 网页端没有效入口（codebuddy.cn/profile/usage 的「签到」按钮是历史残留，已禁用）
  - 断签代价：当周 1000 连签大奖清零，不是单纯少 100 分
  - 赛季制限时活动，每期有截止日期（情报：第 10 季 2026-09-30 至 2026-10-15 已结束；是否开新赛季以客户端为准）
  - 有攻略称 2026 年 5 月起对专业版用户权益可能有调整，以实际显示为准

### 2. 派猫猫旅行
- 收益：每天派猫猫出门，回来带积分 + 能量；约 10 能量开一次 Buddy 盲盒（看脸）
- 入口：个人中心 → Buddy 形象 →「派猫猫旅行」
- 关键事实：当天须与 WorkBuddy 完成至少一次对话，才计入连续登录天数

## 二、一次性 / 限时（有空刷掉）

### 3. 成长计划 / 任务中心
- 收益：单个任务 100–300 积分，全部做完约 1300+
- 已知任务示例（以客户端实际列表为准）：
  - 新建一个任务并发起对话：300
  - 体验「设计创意」模式：300
  - 探索优秀灵感：100
  - 桌面端对话 1 次：100
  - 体验「资料库」：100
- 关键事实：部分任务只奖 Buddy 不奖积分；部分任务耗时长且持续烧积分，达到奖励要求即可停止

### 4. 开学季师生认证（学生专属）
- 在读大学生完成认证，一次性 1000 积分，限时

### 5. 新人积分礼包
- 首次登录自动发放（约 2000–5000，以个人中心到账为准），需去个人中心手动点领取，有效期约 90 天，别过期

## 三、每月自动

### 6. 每月免费额度
- 每月 1 号自动刷新（免费版约 500 分/月），入口：左下角头像 → 个人中心/使用量查看余额

## 四、上不封顶（适合内容创作者）

### 7. 腾讯云开发者社区发文
- 收益：使用心得 +500；教程文章 +1000；被官方精选额外 +2000（单篇最高约 3000）
- 好过审的方向：用 WorkBuddy 完成具体任务的完整实战教程、踩坑记录、效率对比数据、Skill 推荐与配置方法
- 与用户的掘金/小红书创作习惯天然协同：一稿多发，WorkBuddy 实战内容即是积分

### 8. 邀请好友
- 双方各得 +500（有攻略称 650）；好友 30 天内付费，双方再各得 +1000
- 入口：个人中心 → 邀请链接

## 五、省积分技巧（变相攒分）

- 简单任务用 Ask 模式，不要动不动开 Craft，消耗差约一倍
- 单任务单窗口，及时清空上下文，减少隐形消耗
- 轻量任务用限免/免费模型（如 Hy3、Hy4、MiniMax-M2.5 等），不扣积分
- 需求一次说清，减少来回对话轮数
- 任务中心刷奖励时，达到要求即停止，别让任务空跑烧分

## 六、月度收益估算（情报口径）

每日签到底线：100 × 30 + 连签大奖约 4000 ≈ 7000+；加派猫猫、任务中心、每月免费额度，月均 3500 分起步，发文渠道上不封顶。约 1 积分 ≈ 0.05 元算力。

## 七、自动签到工具生态（2026-10-22 检索；仅作情报，本 skill 不接入）

该需求极大（SkillHub 单个积分 skill 下载量约 14.4 万）。代表性项目（检索时均在 1-2 天内更新）：

| 项目 | 平台 | 能力 |
|---|---|---|
| totorosir-workbuddy-score（v3.1.7） | SkillHub | 功能最全：积分余额/连签/活动地图/派猫猫全自动；三通道授权（本机登录态/网页会话/长效令牌） |
| wb-buddy-checkin | ClawHub | v2 端点优先 + legacy 回退；2026-09-29 兼容 v5.6.2 信封加密 |
| lls-teach/lls-workbuddy-checkin | GitHub | v3.3.0+ 走客户端 WBIPC 宿主通道（不碰 token）：查询+自动领取+领后复核+开机兜底；旧版 archive/v3.2.1 才带派猫猫+多渠道推送 |
| TraeWorkAssistant（363★） | GitHub | Trae/WorkBuddy/CodeBuddy/Qoder 多账号签到一体化 |
| 其他十余个 | GitHub | FXmonkey/workbuddy_auto_checkin、TraeSign、ide-daily-checkin、app-cf-checkin（CF Worker cron）、AutoCheckin（macOS Swift）等 |

原版开源 workbuddy-checkin（cat-xierluo/legal-skills，746★ 仓库）已于 2026-09-28 下架，衍生版仍在更新（如 linfeng-zjkg/workbuddy-checkin）。

**两条技术路线与风险**（2026-10-22 逐一核实各项目 README 后修正）：
- **解密路线**（totorosir-workbuddy-score、wb-buddy-checkin、TraeWorkAssistant 等）：靠进程内存扫描/DPAPI/CDP 从 v5.6.2+ 的 AES-256-GCM 信封里挖密钥，明确踩服务协议 9.2(2)/(6) 红线，且官方每次加密升级都会集体失效。TraeWorkAssistant 作者在 README 自述"可能违反服务条款、风险自担"，其豆包功能已因作者多个账号被封而搁置。
- **宿主通道路线**（lls-teach v3.3.0+）：经客户端 WBIPC 转发请求、鉴权头由客户端注入，不读取/不解密/不落盘 token，技术上不碰加密；但仍是自动签到，且依赖官方未公开的 IPC 通道，随时可能被关闭。
- 本 skill 只做提醒与追踪，不接入、不协助安装或复刻此类工具；用户询问时如实说明两条路线的差异与风险。

## 八、合规红线（务必保留）

官方服务协议 9.2 条禁止破解技术保护措施、绕开技术保护、超出常规频率的自动化请求与批量操作；9.4 条违规可限制功能、封禁直至注销账号。**不得用脚本自动签到**——本 skill 只提醒与追踪，领取必须手动。
